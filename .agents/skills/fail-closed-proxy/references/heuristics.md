# Heuristics
- **when mirroring a mediation pipeline onto an MCP path, run decide -> metrics -> audit before forwarding, map deny to a caller-visible tool error and infrastructure faults to protocol errors, forward upstream with Mcp-Method/Mcp-Name headers and a body cap, and scan SSE data lines for the final response**: fail-closed decide-audit-forward mediation on a JSON-RPC/MCP ingress where the upstream may answer JSON or SSE (from trace 26)
- **an MCP ingress needs a non-empty allowed_origins list (empty disables Origin validation), propagated from config into AppState; assert origin 403/200, unsupported-version -32022, header-mismatch -32020, and unknown-method 404 by propagating the upstream error code**: MCP protocol and Origin conformance on a proxy whose upstream may reject methods (from trace 27)
- **return the mapped denial response from the mediation method itself so the deny branch is unit-testable even when the typed request shape cannot express a denied input**: testing deny paths that are unreachable through the public typed request (from trace 28)
